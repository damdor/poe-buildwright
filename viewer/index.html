Path of Exile Build Planner

A fan-made build planner for Path of Exile — both games, one place. PoE2 gets the full toolkit (tree, gems, gear, leveling timeline, typeset guides, .build export); PoE1 gets its real 3.26 passive tree with in-place ascendancies. Your builds stay in this browser, side by side below. Works with any AI assistant.

+ New PoE2 build → The full planner on one page: the 0.5 tree, gems, gear, leveling timeline, and the Build Guide. + New PoE1 build → The 3.26 passive tree with in-place ascendancies — pick a class and start pathing. Tree-only for now.

How it works

1 Plan on the tree Pick a class, click nodes — pathing is automatic. Add gems and gear from the side panels. Hover anything for real in-game numbers.
2 Snapshot the leveling story Hit + SNAPSHOT at milestones. Each one freezes tree, gems, and gear. Scrub the timeline to replay the journey level by level.
3 Read it as a guide Open 📖 Build Guide: your build as a chaptered, typeset guide. Drag it beside the tree — hover anything in the text and it lights up on the tree. Edit the prose inline.

Build with an AI assistant

Have an agent make you a build Any LLM that can browse. No login, no API key — it reads /llms.txt and hands back a share link you just click:
“Read https://<this-site>/llms.txt and make me a Sorceress cold-crit build with leveling snapshots. Give me the share link.”
The details — endpoints, capabilities, OpenAPI, worked examples — live on the agents page.
Have an agent write your guide For a build you made: hit Copy for agent in the Build Guide — the whole story as structured JSON. Paste it to any LLM:
“Turn this into a written leveling guide.” — it already contains the writing instructions.
