PoE2 Build Planner

A fan-made build planner for Path of Exile 2 — plan the tree, gems, and gear; snapshot your leveling; read it back as a typeset guide.
Exports .build files the game reads directly. Works with any AI assistant.

+ New build → Open the planner with a fresh build. Everything happens on one page: the tree, the gems, the gear, the timeline.

How it works

1 Plan on the tree Pick a class, click nodes — pathing is automatic. Add gems and gear from the side panels. Hover anything for real in-game numbers.
2 Snapshot the leveling story Hit + SNAPSHOT at milestones. Each one freezes tree, gems, and gear. Scrub the timeline to replay the journey level by level.
3 Read it as a guide Open 📖 Build Guide: your build as a chaptered, typeset guide. Drag it beside the tree — hover anything in the text and it lights up on the tree. Edit the prose inline.

Build with an AI assistant

Have an agent make you a build Any LLM that can browse. No login, no API key — it reads /llms.txt and hands back a planner link you just click:
“Read https://<this-site>/llms.txt and make me a Sorceress cold-crit build with leveling snapshots. Give me the planner link.”
Have an agent write your guide For a build you made: hit Copy for agent in the Build Guide — the whole story as structured JSON. Paste it to any LLM:
“Turn this into a written leveling guide.” — it already contains the writing instructions.
